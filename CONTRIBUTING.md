# Contributing to Windows Change Control MCP

Thank you for considering contributing to this project!

## How to Contribute

1. Fork the repository
2. Create a new branch for your feature or fix (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Ensure your changes comply with the project's coding standards and pass tests
5. Commit your changes (`git commit -m 'Add some amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Development Process

We follow a gated development process:

- Gate 0: Governance Baseline
- Gate 1: Provider Discovery
- Gate 2: Canonical Operation Model
- Gate 3: Read-Only MCP
- Gate 4: Planning Layer
- Gate 5: Authorization Enforcement
- Gate 6: Execution Broker
- Gate 7: First Controlled Write
- Gate 8: Evidence Assurance
- Gate 9: Provider Expansion
- Gate 10: Security Acceptance

Please ensure your work aligns with the current gate.

## Coding Standards

- Use English for all documentation and comments
- Follow the architectural principles outlined in AGENTS.md
- Write clear, maintainable code
- Include tests for new functionality
- Document any architectural decisions

## Reporting Issues

Please use the GitHub Issues tracker to report bugs or request features.
